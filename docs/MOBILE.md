# Mobile CEO Panel

The first mobile shell is a Progressive Web App (PWA).

## Purpose
- Track opportunities and agents from iPhone
- Review buyer/supplier/price/logistics state
- Read CEO reports
- Keep a visible product-development request area

## Current state
UI shell only. Buttons and live data wiring are intentionally next steps.

## Security
Shadow Mode remains enforced: the mobile UI cannot send offers, sign contracts, issue guarantees, or move money.
