# Global Broker AI — Architecture

## Mission
Find commercially actionable buyer demand across the world, then build the supply side and economics around it. No product or sector is privileged.

## Pipeline
1. Source Agents — public procurement, RFQ and approved data feeds.
2. Normalizer — one Opportunity schema for every source.
3. Buyer Verification Agent — identity, authority and credibility.
4. Supplier Agent — candidate producers/exporters.
5. Price Agent — comparable market/quote evidence.
6. Logistics Agent — route, freight and landed-cost inputs.
7. Trade & Compliance Agent — sanctions/export/import/payment constraints.
8. Risk Agent — counterparty and execution risks.
9. Deal Score — ranks evidence-backed opportunities.
10. CEO Agent — concise decision report.
11. Communication/Negotiation/Contract agents — disabled in Shadow Mode.

## Hard gates
No outbound message, binding offer, contract, guarantee or money movement without explicit human approval.

## Data principle
Unknown values remain unknown. Agents must not invent price, supplier, margin, buyer verification or closing probability.
